# Northstar

Northstar is a product design case study for a guided AI website builder focused on one core problem: AI can generate a site quickly, but it still struggles to make the result feel specific, editable, and trustworthy.

The concept explores how an AI-powered WordPress experience could move beyond one-shot generation and instead guide users through:

- a plain-language business brief
- visible AI reasoning and recommendation logic
- meaningful preview comparison
- guided refinement
- a calmer handoff into editing

## Project Summary

This case study is centered on a lightly anonymized AI website-builder concept called `Northstar`. The product is designed around the idea that personalization should happen inside generation, not as a rescue step afterward.

The page covers:

- the product problem and category quality gaps
- key user types and trust needs
- the core interaction model
- featured product moments from brief to editor handoff
- edge cases, tradeoffs, and next-step validation questions
